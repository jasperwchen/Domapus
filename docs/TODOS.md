### 1e. Custom domain (medium)

A domain such as `domapus.com` reads as a product and keeps search ranking under a name you
own. GitHub redirects the old `github.io` URL on its own. The cost is that the site moves from
`/Domapus/` to the root, so the Vite base path, the 404 fallback, the canonical link, the
sitemap, the social-preview URLs and the structured data all change together; the landing
pages take the base from Vite and their origin from `SITE_ORIGIN` in `scripts/build-pages.mjs`.
Decide before the landing pages are deployed and before the posting routine, because links
earned on the old URL are worth less after a move. After that: cache lifetime, title, favicon

## 2. Something only you can do

### 2a. Forward the new events from Google Tag Manager to GA4 (small, after the events deploy)

In Tag Manager (tagmanager.google.com, container GTM-PNP9L5ZD):

1. Variables, User-Defined Variables, New, type "Data Layer Variable". Make one per key, with
   the key as the variable name: `metric`, `state`, `metro`, `method`, `search_type`,
   `search_term`, `found`, `enabled`, `has_zip`, `has_view`, `value_ms`, `embed_host`.
2. Triggers, New, type "Custom Event". Tick "Use regex matching" and set the event name to
   `metric_change|zip_select|search|compare_open|auto_scale_toggle|deep_link_open|map_first_colour|embed_view|embed_copy`.
3. Tags, New, type "Google Analytics: GA4 Event". Pick the existing GA4 measurement ID. Set
   the event name to the built-in variable `{{Event}}`. Under Event Parameters add one row per
   key from step 1, parameter name equal to the key, value the matching variable. Attach the
   trigger from step 2.
4. Press Preview, open the site, click around, and confirm each event fires the tag. Then
   Submit to publish the container.

In GA4 (Admin, Data display, Custom definitions):

5. Create an event-scoped custom dimension for each of: `metric`, `state`, `metro`, `method`,
   `search_type`, `search_term`, `found`, `enabled`, `embed_host`.
6. On the Custom metrics tab create `value_ms`, unit milliseconds.
7. Admin, Data display, Events: mark `zip_select` as a key event. It is the activation signal.

New dimensions show in reports a day or two later. DebugView shows events at once while Tag
Manager's Preview is open.
